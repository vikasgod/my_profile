# Vikas G God - My Profile

Animated React portfolio built with Vite, React, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Add your resume

Copy your PDF into:

`public/resume.pdf`

The Download Resume button already points to `/resume.pdf`.

## Customize

Most portfolio content is in:

`src/data/portfolioData.js`

Update GitHub and LinkedIn URLs in `src/App.jsx`.
